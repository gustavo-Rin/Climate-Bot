# Climate-Bot
Un bot hecho para el uso diario e integrado en Discord. Desde crear listas y temporizadores hasta recordarte consejos útiles cada día. Su propósito original es listar elementos que pueden ser perjudiciales para el planeta. Este bot tendrá comandos como (crear lista, Leer Lista x, Recuérdame en 20 minutos (el bot te mencionará en el chat), ¿está x incluido en la Lista y? (para no tener que revisar cada elemento individualmente en una lista)).
El uso original de este bot es usarlo para conservar el planeta. Por ejemplo cuando uno necesita saber cualers ingredientes son malos para el planeta y uno mismo uno le podria preguntar a el bot y el bot usara una de sus multiples listas para ayudarle. Tambien te daria recomendaciones diarias de habitos los cuales podrias seguir para conservar el planeta.
